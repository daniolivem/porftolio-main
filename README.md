# Portfólio em HTML, CSS e JavaScript

Bem-vindo ao repositório do meu portfólio! Este projeto foi criado como parte de um desafio acadêmico e agora está estruturado com HTML, CSS e JavaScript, seguindo uma organização de pastas mais clara.

## 📖 Sobre

O objetivo deste portfólio é apresentar minhas informações, experiências e projetos de forma simples e objetiva, com uma base visual criada em CSS e pequenos recursos de JavaScript para melhorar a navegação.

## 📁 Estrutura de Pastas

- `assets/img/` imagens do projeto
- `css/` estilos globais
- `js/` scripts JavaScript (conteúdo renderizado dinamicamente)
- `index.html` como página única (SPA)

## 🚀 Como Visualizar

Você pode acessar a versão online pelo GitHub Pages ou baixar/clonar este repositório e abrir o arquivo `index.html` em seu navegador.
